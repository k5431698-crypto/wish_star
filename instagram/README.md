# 인스타그램 작업 안내 (인스타 전용 세션용)

> 이 폴더는 **인스타그램 영상 기획·자막·소리·캡션**만 다룹니다. 사이트 코드(`map.js` 등)는 **개발 세션**이 맡으니 건드리지 마세요.
> 먼저 저장소 루트의 `NOTES.md`를 읽어 서비스 상황을 파악하세요.

## 계정 컨셉 (사용자 결정, 가칭)
- **직장인이 퇴근 후 조금씩 만드는 예쁜 몽환적 공간**. 형식: "오늘은 ○○ 했어요~"
- 나중에 비행기를 타고 날아다니고, 배를 타고 옆 모래사장에 가는 장면까지 확장 예정
- 가칭 계정 이름: "퇴근 후 달빛섬" (사용자가 정하면 바꿈)
- 서비스 본체는 "소원 별 우체국"(익명으로 고민·소원을 올리고 모르는 사람이 답장, 마음에 든 답장에 별). 영상에서는 처음엔 분위기 위주, 서비스 소개는 나중에

## 영상 형식 (제안, 사용자와 확정)
- 세로 9:16, 5~15초, **첫 2초에 가장 압도적인 장면**, 마지막에 "오늘은 ○○ 했어요~" 한 줄
- 자막 + 잔잔한 분위기 소리(바람·모닥불·파도). **처음엔 TTS 없이** 자막+소리 위주
- 촬영: 사용자가 폰 화면 녹화. 주소 `https://k5431698-crypto.github.io/wish_star/map.html?cine=1` (글자 숨김, 카메라 자동 이동, 최대 해상도)

## 지켜야 할 것
- 개인정보: 회사 이름·위치·얼굴 노출 금지(직장인이라는 사실만)
- 음악·이미지: 저작권 없는 소리(직접 합성)나 인스타 앱 내 라이선스 음악만. 사용자가 준 참고 사진·남의 캐릭터(산사 등)는 영상에 쓰지 않음
- **인스타에 직접 올릴 수 없음**: 영상·캡션을 만들어 주면 사용자가 직접 업로드
- 영상 파일은 사용자가 캡컷으로 편집. 이 세션은 기획·자막(SRT)·소리·캡션을 맡음. 이 환경에는 ffmpeg가 있고, Python으로 소리 합성 가능
- 한국어로 짧고 쉽게 답하기. 모호하면 먼저 질문. 큰 변경 금지

## 작업 규칙
- 단계마다 한국어로 짧게 커밋, `main`에 push. **개발 세션과 충돌하지 않게 이 폴더(`instagram/`)만 수정**, push 전에 `git pull --rebase origin main`
- 생성한 소리(wav/mp3)와 자막은 `instagram/assets/`, 기획 문서는 `instagram/plan/`에 둠. 큰 파일(영상)은 저장소에 올리지 않음
