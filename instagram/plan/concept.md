# 계정 컨셉 한 장 정리

## 한 줄 컨셉
**출퇴근 왕복 2시간 반인 직장인이, 퇴근 후 조금씩 만드는 나만의 휴식 공간.**
(몽환적인 달빛 섬을 AI와 함께 매일 조금씩 키워 가는 기록)

## 이야기 틀 (빌드 인 퍼블릭)
- 주인공: 평범한 직장인(회사·얼굴·위치는 절대 안 보임)
- 소재: 코딩을 모르는 사람이 Claude Code로 폰만 써서 3D 섬을 만드는 과정
- 매 영상 = "오늘은 ○○ 했어요~" 한 가지 변화만 (나무 추가, 바람 불게 함, 모닥불 켬 등)
- 설명은 **짧고 쉬운 말 한두 줄**, 어려운 용어 금지
- 마지막에 질문 한 줄로 **댓글 피드백** 받기 ("다음엔 뭘 넣을까요?")

## 영상 형식
- 세로 9:16, 5~15초, 첫 2초에 가장 예쁜 장면
- 자막 + 직접 합성한 분위기 소리(바람·모닥불·파도). 처음엔 TTS 없음
- 마지막 자막: "오늘은 ○○ 했어요~" + 댓글 질문

## 피드백 루프
1. 영상 올림 → 2. 댓글로 "뭐 고칠까요/넣을까요" 질문 → 3. 댓글 중 1~2개 골라 다음 편에 반영 → 4. 반영했다고 "○○님 의견으로 ○○ 했어요~" 소개
→ 보는 사람이 같이 만드는 느낌, 재방문 이유가 생김

## 주의
- 요즘 유행하는 '산사' 분위기는 참고만. 산사 캐릭터·그림은 쓰지 않음(저작권)
- 회사·위치·얼굴·참고 사진(남의 것) 노출 금지
- "직장인이 이만큼 만들었다"는 자랑보다 "같이 구경해요" 톤
